# 2026-04-08 化学实验课历史记录

顾明澜老师说明，本阶段实验课只训练酸碱滴定的基本操作、终点判断和误差分析，不进入氧化还原滴定、络合滴定，也不使用自动滴定仪。课堂和复习材料都应按“实验目的、关键步骤、原始数据、误差来源、改进动作”五个栏目整理，不按发言顺序写流水账。

全班需要遵守三项固定约束。第一，移液管和滴定管必须先用待装溶液润洗，读数时视线与液面最低点保持水平。第二，平行样至少做三组；如果任意两组计算结果的相对偏差超过 0.5%，不能直接取平均，必须补做一组并在报告中说明。第三，涉及浓酸或浓碱时必须佩戴护目镜，废液统一倒入标记容器，不能直接排入水槽。

顾明澜决定先使用统一实验报告模板，所有结论必须能回链到原始读数，不能只写最终浓度。班级报告的第一轮提交截止时间是下周二，也就是 2026-04-14 22:00，提交到课程平台。实验小组长负责在提交前检查成员是否写明初读数、末读数和有效数字。

上次预实验暴露出三个持续风险：有同学把酚酞刚出现浅粉色与深粉色都当成终点；有人在滴定管尖嘴仍有气泡时开始读数；还有小组只保留计算后的平均值，没有保留三组原始数据。顾明澜要求后续摘要把这些风险放在任务前面，便于课前快速提醒。

苏妍负责把“终点颜色过深”和“尖嘴气泡”两个常见错误整理成一页图文提醒，在明天中午，也就是 2026-04-09 12:00 前发到班级实验群。蔡文博负责汇总各组滴定管初读数和末读数的填写示例，在本周五 17:00 前交给顾明澜。两份材料都必须使用匿名示例，不能出现学生姓名和成绩。

顾明澜的摘要偏好是先写“仍然有效的规范”，再写“本次状态变化”，最后列“负责人、动作、截止时间”；对于尚未核实的数据必须标记为待确认，不能自行补全。
